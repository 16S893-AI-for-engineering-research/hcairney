## What I added

I added a custom plotting skill intended for use in generating plotting scripts which generate plots I use in my weekly meetings with my advisor.

## Why I added it

I have been using agents to write plotting scripts for a while now, but I usually have to go back and edit by hand different settings to get it to look right in the slides I show my advisor. Therefore I thought it would be useful to have a skill which I can use to give the agent an idea of what I would like from the get-go to make the plot-making process a little smoother. I have not yet had a chance to play around with this skill too much yet, and I imagine I will keep tinkering with it to get the behavior I would like.

## How I used the agent

I put the template SKILL.md file in place and then asked the agent to start filling out the body of the skill according to some initial prompts about figure size and font sizes. I also asked the agent to recommend some additional settings that would be good to include in the skill and then asked the agent to edit the body of the skill according to my feedback on those points.
